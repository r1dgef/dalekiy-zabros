# Далёкий заброс

Браузерная коллекционная рыбалка для VK Игры.

## Возможности

- механика заброса, поклёвки и вываживания;
- три локации, открывающиеся каждые 10 уровней силы;
- 45 коллекционных видов;
- личные рекорды веса;
- ежедневные задания и серии входов;
- VK Bridge, rewarded и interstitial реклама;
- рейтинг друзей и приглашения;
- сохранение прогресса в браузере.

## Запуск

Игра не требует сборки. Разместите `index.html` и папку `assets` на любом HTTPS-хостинге.

Основная инструкция публикации: [DEPLOYMENT.md](DEPLOYMENT.md).
